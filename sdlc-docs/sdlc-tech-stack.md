# Pre-Dev Software & Tools

Pre-dev স্টেজে (planning, research, requirement gathering, design ইত্যাদি) যেসব সফটওয়্যার/টুল ব্যবহার করা হবে তার তালিকা নিচে দেওয়া হলো।

| Software Name | Description |
|---|---|
| Notion | Requirement, note ও documentation একসাথে গুছিয়ে রাখার জন্য ব্যবহৃত টুল।<br>https://www.notion.so |
| Trello | Task ও project management-এর জন্য ব্যবহৃত board-based টুল।<br>https://trello.com |
| Google Docs | Requirement document ও meeting note লেখার জন্য ব্যবহৃত কোলাবোরেটিভ টুল।<br>https://docs.google.com |
| draw.io (diagrams.net) | System architecture ও flow diagram আঁকার জন্য ব্যবহৃত ফ্রি টুল।<br>https://draw.io |
| GitMind | Mind map ও flowchart বানিয়ে idea/planning ভিজ্যুয়ালাইজ করার জন্য ব্যবহৃত টুল।<br>https://gitmind.com/ |
